Preferences and drafts both wait on this choice. A cookie added later calls whenAllowed and uses the same answer. This page passes #privacy so the link stays here.

A saved cookieconsent_status of allow, deny, or dismiss is kept. Dismiss is not approval. Required cookies are not part of this question.

import { crumbnod, start, whenAllowed } from 'crumbnod';

crumbnod({ privacy: '#privacy' });

whenAllowed(() => rememberPreferences());
whenAllowed(() => keepDrafts());

start();
